# Статус реализации

Документ отражает фактическое состояние, а не план. Обновляется по завершении
каждого этапа.

## Готово и проверено

### Инфраструктура
* Next.js 16 + React 19 + TypeScript (строгий режим, `noUncheckedIndexedAccess`).
* PostgreSQL + Prisma 7 (драйвер-адаптер `@prisma/adapter-pg`), миграции применяются.
* Tailwind CSS 4, дизайн-система в `src/components/ui`.
* ESLint 9 (flat config) + Vitest. `npm run verify` проходит.
* Docker и `docker compose` для локального запуска и Railway.

### Безопасность
* Регистрация и вход, bcrypt (12 раундов), сессия в `httpOnly`-cookie с
  серверным реестром и возможностью отзыва.
* Мультитенантность: каждая выборка фильтруется по `companyId` из сессии.
* Роли `OWNER` / `ADMIN` / `ANALYST` / `VIEWER`, проверка на сервере.
* Журнал операций `audit_logs`.
* Секреты только в переменных окружения, `.env` исключён из Git.

### Модуль №1 — Financial Intelligence
Полностью работает, покрыт автотестами (93 теста):

* Выручка с разделением НДС, с учётом статуса плательщика.
* Полная себестоимость: товары, прочие прямые, логистика, таможня, ФОТ и
  налоги с ФОТ, субподряд, накладные, резерв, невозмещаемый НДС, банковские
  комиссии, проценты по займу, стоимость обеспечений, гарантийный резерв.
* Валовая, операционная и чистая прибыль; рентабельность продаж.
* ROI с явной формулой и приведением к году.
* Минимальная безубыточная цена и цена под целевую прибыль (численное решение
  с точностью до 1 тиына).
* Потребность в оборотном капитале, пиковый кассовый разрыв с датой.
* Стоимость финансирования, включая автоматический расчёт из кассового разрыва.
* Прогноз ДДС по дням с расшифровкой каждого движения.
* Чувствительность к снижению цены и росту затрат.
* Сценарии: оптимистичный, базовый, стрессовый — с показом параметров.
* Расшифровка формул и смысла для 12 ключевых показателей.
* Список недостающих данных и предупреждения о типичных ошибках расчёта.
* Налоговые ставки — конфигурация с источником и датой актуальности.

### Работа с тендерами
* Создание, редактирование, удаление, смена стадии.
* Список тендеров, карточка тендера с рабочим процессом из 7 шагов.
* Сохранение и история финансовых расчётов (результат пересчитывается на
  сервере, клиентскому результату не доверяем).
* Главный экран со сводкой и графиками.

## Что требуется для завершения интеграций

* **Anthropic API-ключ** (`ANTHROPIC_API_KEY`) — без него AI-модули недоступны;
  интерфейс честно показывает это состояние, остальная часть работает.
* **Доступ к данным порталов закупок** — модуль №3 начинается с импорта
  открытых данных и файлов. Подключение внешних API возможно только при наличии
  законного доступа и токенов. Фиктивная статистика по реальным закупкам
  не генерируется.
