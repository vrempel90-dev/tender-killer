# Налоговые ставки: источники и порядок обновления

## Принцип

Ни одна ставка не «вшита» в расчёт без источника и даты начала действия.
Значения по умолчанию объявлены в `src/lib/finance/tax-config.ts` и загружаются
в таблицу `tax_rate_configs` командой `npm run db:seed`. После загрузки их можно
изменять — движок читает ставки из базы.

Каждая запись содержит: машинный ключ, название, значение, название источника,
ссылку на источник, дату начала и окончания действия, примечание.

## Значения по умолчанию

Основной источник: **Налоговый кодекс Республики Казахстан от 18 июля 2025 года
№ 214-VIII**, действует с 1 января 2026 года
(<https://adilet.zan.kz/rus/docs/K2500000214>).

| Ключ | Значение | Источник | Действует с |

| `VAT_SOCIAL_SPHERE` | 5 % ⚠️ | НК РК № 214-VIII, льготные ставки | 01.01.2026–31.12.2026 |
| `VAT_REGISTRATION_THRESHOLD_MCI` | 10 000 МРП | НК РК № 214-VIII | 01.01.2026 |
| `MCI_MONTHLY_CALC_INDEX_KZT` | 4 325 ₸ ⚠️ | Закон о республиканском бюджете на 2026–2028 гг. | 01.01.2026 |
| `CIT_STANDARD` | 20 % | НК РК № 214-VIII, ст. 313 п. 1 | 01.01.2026 |
| `CIT_BANKS_GAMBLING` | 25 % | НК РК № 214-VIII, ст. 313 п. 2 | 01.01.2026 |
| `SIMPLIFIED_DECLARATION_RATE` | 4 % ⚠️ | НК РК № 214-VIII, СНР на основе упрощённой декларации | 01.01.2026 |

| `PROCUREMENT_PERFORMANCE_SECURITY_PERCENT` | 3 % | Закон РК «О государственных закупках» | 01.01.2026 |

⚠️ — значение взято из обзорных публикаций, а не из официального текста нормы.
В базе такие записи помечены примечанием `ТРЕБУЕТ СВЕРКИ С ПЕРВОИСТОЧНИКОМ`,
в интерфейсе — отдельным признаком. **Перед использованием в коммерческих
расчётах сверьте их с текстом Налогового кодекса на `adilet.zan.kz` и
разъяснениями Комитета государственных доходов МФ РК.**

Отдельно о `PAYROLL_TOTAL_EMPLOYER_BURDEN`: 24 % — это ориентир совокупной
нагрузки работодателя (социальный налог, социальные отчисления, ОПВР, ВОСМС,
ООСМС). Фактическая величина зависит от вида выплат, лимитов по доходу и
статуса работника. Значение нужно уточнить у бухгалтера и заменить в настройках.

## Как налоговый режим влияет на расчёт

| Режим | НДС по внутренним оборотам | База налога на доход |
|---|---|---|
| Общеустановленный, плательщик НДС | да | прибыль |
| Общеустановленный, не плательщик НДС | нет | прибыль |
| Упрощённая декларация (СНР) | нет* | **оборот** |
| Розничный налог (СНР) | нет* | **оборот** |
| ИП, общеустановленный режим | да | прибыль |

\* Применяющий специальный налоговый режим не подлежит постановке на
регистрационный учёт по НДС; регистрация возможна только в общеустановленном
порядке. Движок принудительно снимает флаг «плательщик НДС» для режимов СНР,
даже если он передан в запросе. НДС по импорту при этом остаётся отдельным
обязательством и учитывается в расчёте.

## Как обновить ставку

1. Проверьте действующую норму в первоисточнике.
2. Измените запись в таблице `tax_rate_configs` (раздел «Настройки → Налоги»
   или напрямую в БД). Старую запись не удаляйте: ставки версионируются по
   `effectiveFrom`, что позволяет пересчитывать прошлые тендеры по прежним
   нормам.
3. Если меняется набор ставок по умолчанию, обновите
   `src/lib/finance/tax-config.ts` и поднимите `TAX_CONFIG_VERSION`.
   Версия конфига сохраняется в каждом расчёте — по ней видно, по каким
   правилам считали.
